## SCRUM-2 : 
En tant que visiteur, je veux créer un compte en fournissant mes infos personnelles

### Tâches associées :
- Créer le formulaire d'inscription avec les champs nécessaires (nom, email, mot de passe…)
- Implémenter la logique de création de compte côté back-end
- Valider les données saisies (format email, mot de passe fort…)

## SCRUM-3 : 
En tant qu’utilisateur, je veux me connecter à mon compte

### Tâches associées :
- Créer une page de connexion avec un formulaire.
- Implémenter la validation des champs (email et mot de passe).
- Ajouter une fonctionnalité de connexion avec gestion des erreurs (mauvais identifiants).
- Implémenter un système de redirection après connexion réussie.
- Stocker l'état de la session de l'utilisateur (par exemple via des cookies ou un token).
